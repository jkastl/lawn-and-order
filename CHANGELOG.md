# Changelog

All notable changes to this project. Versions follow [Semantic Versioning](https://semver.org/):

- **Major:** the plan changes shape, such as a new scope, a restructured site or breaking data-format changes.
- **Minor:** new features, sections or plan content.
- **Patch:** fixes, wording and data corrections.

The current version is in [`VERSION`](VERSION). When it changes on `main`, a `vX.Y.Z` tag and a GitHub release are created automatically from the matching section below. Versions before 1.3.0 were numbered after the fact and aren't tagged.

## [1.3.0] - 2026-11-07

### Added
- Semantic versioning: a `VERSION` file, this changelog, the version in the site footer, a CI check that keeps them in step, and automatic tags and releases.

### Removed
- The location and "plan as of" line above the site's headline.

## [1.2.0] - 2026-11-07

### Added
- A "Choose an area" list under the site model, with swatches that match the map, plus a bold outline on the selected area.
- An "Answered" list under the open questions.

### Changed
- The south border and the fence edge of the shade bed use wet-tolerant plants, because the south fence line stays wet.
- The rain barrel overflow stays away from the south fence line.
- Weeding is by hand only, with no herbicides.
- The old beehive is being removed before Phase 2.
- Five work weekends instead of six. Base budget is $1,271–$1,956, or $871–$1,556 after Lawns to Legumes.

### Removed
- The "Whole lot" map view.
- All boulevard work. The boulevard is already a bee lawn and isn't part of the renovation; its rules stay in the plan doc as reference.
- The HOA rule (no HOA applies).

## [1.1.0] - 2026-11-06

### Added
- Link-preview and SEO tags: canonical URL, Open Graph, Twitter card and JSON-LD, plus a 1200×630 preview image.
- GoatCounter page counts (no cookies, no personal data), allowed by the Content Security Policy.

## [1.0.0] - 2026-11-06

### Added
- The mobile-friendly website on GitHub Pages: site model, zones, bloom calendar, timeline checklist, budget calculator, rules, programs and open questions.
- The budget as JSON, CSV and Markdown, replacing the Excel workbook.
- Privacy guardrails: a PII checker, git hooks, CI, and a Pages deploy gated on the check.
- The written conversion plan.
